# Сервис заказов

Автор: Лисенков Станислав

## Как запустить

Команды выполняются из корневой папки проекта (рядом с `go.mod`):

```bash
gofmt -w .
go mod tidy
go list ./...
go build ./...
go vet ./...
go run ./cmd/orders
HTTP_ADDR=:9090 go run ./cmd/orders
```

## Конфигурация

- **Имя настройки**: переменная окружения `HTTP_ADDR`
- **Значение по умолчанию**: `:8080` (используется, если переменная `HTTP_ADDR` не задана или пустая)

## Роль каждого пакета

- `cmd/orders` — точка входа в программу (`main.go`). Загружает конфигурацию, создаёт хранилище, сервис и обработчик, связывает их между собой и запускает создание заказа.
- `internal/config` — отвечает за чтение настроек из переменных окружения (`HTTP_ADDR`) и подстановку значения по умолчанию (`:8080`).
- `internal/model` — хранит базовую структуру данных заказа `Order`.
- `internal/repository` — отвечает за хранение заказов в памяти (`Memory`), умеет сохранять заказ (`Save`) и находить его по номеру (`ByID`).
- `internal/service` — содержит бизнес-логику создания заказа (`Service`), проверяет, что имя покупателя не пустое, выдаёт новый `ID` и работает с хранилищем через интерфейс `Repository`.
- `internal/handler` — принимает запрос на создание заказа (`Handler`) и передаёт его в сервис через локальный интерфейс.
